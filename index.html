Featured Projects

Edge-Enabled Skeletal Movement Analysis for Real-Time Fall Risk Detection

Research & Computer Vision · 2026

Final-year research project (CareSense group, R26-DS-010): built a privacy-preserving fall-risk detector that runs on an ordinary RGB webcam and a CPU, analysing skeleton data only. Fused an ST-GCN model with 18 biomechanical features in a late-fusion architecture, trained on NTU RGB+D and UR Fall Detection (578 labelled clips). Achieved 97.12% accuracy, 92.31% sensitivity, a 1.28% false-alarm rate and ROC-AUC 0.9836 on unseen subjects, with 4.5ms CPU inference per window. Measured domain shift (cross-dataset ROC-AUC 0.410) and recovered to macro-F1 0.8851 on webcam data using just 35 fine-tuning clips.

Technologies:
Python PyTorch MediaPipe ST-GCN Computer Vision
Impact:

Real-time, privacy-preserving fall detection deployable on commodity hardware for elder/patient care facilities. See caresense-portfolio.vercel.app
